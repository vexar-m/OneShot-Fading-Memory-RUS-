## Установка Русификатора

```
--========================================================--
    >>>            Установка Русификатора            <<<    
--========================================================--
```

1. Распакуйте файлы русификатора в **корневую папку мода** с заменой файлов подряд.
2. Запустите игру через стандартный лаунчер (`steamshim.exe` или через Steam).
3. Перед установкой рекомендуется сделать **резервную копию** папки с игрой.
